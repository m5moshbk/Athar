# M5mOsH — Athar | أثر

مبادرة رقمية عربية لنشر الخير الموثوق، والتعريف بأبواب الصدقة الجارية والعمل التطوعي، والدلالة على القنوات الرسمية للجهات الخيرية.

## الحالة
- النسخة: 0.1.0
- الحالة: نموذج تعريفي عام أولي
- اللغة: العربية (RTL)
- الاستضافة: لم يتم تفعيل GitHub Pages تلقائياً
- لا يوجد ادعاء بصدور ترخيص أو اكتساب صفة جمعية/مؤسسة.

## حدود النسخة العامة
- لا تستقبل تبرعات أو مدفوعات.
- لا تجمع بيانات متبرعين أو مستفيدين.
- لا تعرض حسابات بنكية أو روابط حملات غير متحقق منها.
- لا تصدر فتاوى ولا تعتمد مخرجات الذكاء الاصطناعي وحدها.
- لا تمثل أي جهة خيرية ما لم توجد موافقة واتفاقية مكتوبة.

## الملفات
- `index.html`: صفحة تعريفية ثابتة.
- `docs/GOVERNANCE.md`: مبادئ الحوكمة.
- `docs/ROLES_AND_ACCESS.md`: أدوار المتعاونين والصلاحيات.
- `docs/CONTENT_VERIFICATION.md`: سياسة التحقق والنشر.
- `docs/ROADMAP.md`: مراحل التطوير.

## التشغيل المحلي
افتح `index.html` مباشرة في متصفح حديث. لا توجد تبعيات خارجية أو أدوات تتبع مضمنة.

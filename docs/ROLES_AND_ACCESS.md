# الأدوار والصلاحيات

## المبدأ
Least Privilege — أقل صلاحية لازمة، محددة بالنطاق والمدة، مع سجل تدقيق. لا تمنح أي صلاحية مالية أو قانونية تلقائياً بسبب التعاقد.

| الدور | المسموح | المحظور افتراضياً |
|---|---|---|
| محرر | إعداد مسودات المحتوى | النشر النهائي، اعتماد أحاديث أو فتاوى |
| مدقق مصادر | فحص المراجع وتوثيقها | إصدار فتوى أو اعتماد حملة مالية |
| مدير محتوى | جدولة المسودات ومراجعة الجودة | جمع التبرعات أو تمثيل كيان |
| منسق شراكات | إعداد قائمة جهات ومراسلات أولية | توقيع اتفاقيات أو تقديم وعود باسم المبادرة |
| مدير مشروع | توزيع المهام ومتابعة التسليم | تجاوز حدود العقد أو الميزانية |
| مدقق امتثال | مراجعة السجلات والمخاطر | تعديل الأدلة أو اعتماد عمله منفرداً |
| مسؤول مالي لدى كيان مرخص | مهام مالية محددة بتفويض نظامي مستقل | استخدام حسابات شخصية أو خلط الأموال |

## دورة منح الصلاحية
1. تحديد المهمة والغرض.
2. التحقق من الهوية والصفة عند الحاجة.
3. توقيع اتفاقية ونطاق عمل مناسبين.
4. تحديد الصلاحية والمدة والبيانات المتاحة.
5. تفعيل أقل وصول ممكن.
6. مراجعة دورية وسحب الوصول عند انتهاء المهمة.

## ضوابط إلزامية
- لا مشاركة كلمات المرور أو مفاتيح API.
- استخدام حسابات فردية ومصادقة متعددة العوامل حيثما أمكن.
- لا تنزيل بيانات مستفيدين إلا عند الضرورة وبموافقة نظامية.
- لا دفع أو تحصيل أو تحويل دون تفويض رسمي منفصل.
- لا توقيع عقود أو نشر حملات باسم جهة أخرى دون تفويض مكتوب.
- توثيق الموافقات والتغييرات والإلغاءات.

هذه مصفوفة تشغيلية أولية وليست بديلاً عن مراجعة قانونية أو لائحة صلاحيات كيان مرخص.

# خارطة الطريق

## المرحلة 0 — النسخة التعريفية
- [x] إنشاء صفحة عربية ثابتة.
- [x] توضيح أن الموقع لا يجمع التبرعات.
- [x] إضافة مسودات الحوكمة والصلاحيات والتحقق.
- [ ] مراجعة بشرية للمحتوى قبل تفعيل الاستضافة العامة.

## المرحلة 1 — التحقق والشراكات
- [ ] تحديد الشكل القانوني المناسب ومراجعة المتطلبات الرسمية الحالية.
- [ ] حصر جهات خيرية مرخصة والتحقق من بياناتها من مصادر رسمية.
- [ ] إعداد نموذج اتفاقية شراكة ومراجعته قانونياً.
- [ ] تحديد مسؤول حماية البيانات وآلية معالجة الطلبات.

## المرحلة 2 — دليل الخير
- [ ] بناء سجل جهات ومشاريع بمصدر وتاريخ تحقق وحالة صلاحية.
- [ ] آلية مراجعة دورية للروابط والتراخيص.
- [ ] عدم عرض رابط تبرع إلا بعد تحقق مستقل وموافقة الجهة صاحبة العلاقة.

## المرحلة 3 — النشر اليومي
- [ ] إعداد تقويم محتوى.
- [ ] إنشاء مسودات آلية مع مصادر قابلة للفحص.
- [ ] اعتماد بشري قبل النشر.
- [ ] سجل تصحيح وبلاغات.

## المرحلة 4 — التشغيل المؤسسي
- [ ] دراسة تأسيس كيان مستقل مع الجهة المختصة.
- [ ] إكمال المتطلبات القانونية والحوكمة.
- [ ] تفعيل حسابات وصلاحيات المتعاقدين بعد التحقق والتفويض.
- [ ] اختبار أمني وخصوصية قبل أي جمع بيانات.

## بوابات الإطلاق
لا يُفعّل أي جمع تبرعات أو استقبال أموال أو إدارة مستفيدين أو تمثيل رسمي قبل استكمال الموافقات والتراخيص والعقود المطلوبة والتحقق منها.

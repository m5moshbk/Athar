# الحوكمة والامتثال — منظومة أثر

## الغرض
تحديد حدود المبادرة الرقمية ومنع الخلط بين النشر التوعوي والنشاط الخيري المرخص أو جمع التبرعات.

## مبادئ ملزمة
1. الشفافية: توضيح صفة المبادرة وحالتها القانونية بدقة.
2. عدم جمع الأموال: لا استقبال أو تحويل أو حفظ أموال تبرعات في هذه النسخة.
3. التحقق: لا نشر لاسم جهة أو مشروع أو رابط تبرع قبل التحقق من مصدر رسمي وحالة الترخيص ونطاق الإذن.
4. الخصوصية: عدم جمع بيانات المتبرعين أو المستفيدين أو نشر صورهم/قصصهم دون أساس نظامي وموافقة صحيحة.
5. فصل المهام: من يُعد المحتوى لا يعتمد وحده الادعاءات الحساسة أو الروابط المالية.
6. سجل الأدلة: لكل مادة حساسة مصدر وتاريخ تحقق ومسؤول مراجعة.
7. الموافقات: أي انتقال إلى نشاط منظم أو التزام مالي أو تعاقد أو معالجة بيانات يتطلب مراجعة قانونية وموافقة صريحة مستقلة.

## المسارات الثلاثة
- كيان مستقل: دراسة خيارات التأسيس ومتطلبات الجهة المختصة؛ لا ادعاء بالترخيص قبل صدوره.
- منصة تقنية: تقديم خدمات تقنية للجهات المرخصة وفق عقد مكتوب يحدد المسؤوليات والبيانات والصلاحيات.
- مبادرة إعلامية: نشر محتوى توعوي غير جامع للتبرعات، مع احترام الأنظمة ذات الصلة.

## حوكمة الذكاء الاصطناعي
- يقتصر دوره على البحث الأولي، تنظيم المصادر، وإعداد المسودات.
- لا يصدر فتوى، ولا يقرر أهلية جهة، ولا يعتمد حملة تبرع.
- يجب إظهار عدم اليقين وعدم اختلاق المراجع.
- تُراجع النصوص الشرعية والادعاءات القانونية بشرياً قبل النشر.

## إدارة الحوادث
عند اكتشاف رابط مضلل أو محتوى غير صحيح أو تسرب بيانات: أوقف المادة المتأثرة، احتفظ بسجل الواقعة دون نسخ بيانات حساسة، أخطر المسؤول المخول، وصحح أو احذف وفق إجراء موثق.

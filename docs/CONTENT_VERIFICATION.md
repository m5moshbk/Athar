# سياسة التحقق من المحتوى والنشر

## أنواع المحتوى
- آية قرآنية: النص مضبوط قدر الإمكان، مع اسم السورة ورقم الآية ومصدر مصحف موثوق.
- حديث: لا ينشر إلا مع مصدر التخريج ودرجة الحديث من مرجع معتبر؛ عند الخلاف يوضح الخلاف أو يستبعد.
- معلومة شرعية: لا تُعرض كفتوى؛ تُحال المسائل المتخصصة إلى جهة إفتاء أو عالم مؤهل.
- فرصة خير: لا تنشر دعوة مالية إلا بعد التحقق من الجهة والقناة والترخيص ونطاق الإذن.
- قصة أثر: لا تنشر بيانات شخصية أو صور مستفيدين دون موافقة صحيحة ومسوغ نظامي.

## سجل كل منشور
يجب أن يتضمن معرفاً فريداً، وتاريخ الإعداد، والنص، ونوع المحتوى، والمصدر الأصلي ورابطه وتاريخ الوصول، والمراجع، وحالة التحقق، وملاحظات الخلاف، وتاريخ المراجعة أو التصحيح.

## حالات التحقق
- VERIFIED: تم التحقق من المصدر والنص.
- NEEDS_REVIEW: يحتاج مراجعة بشرية.
- UNVERIFIED: لا ينشر.
- CORRECTED: صحح مع الاحتفاظ بسجل التعديل.

## سير العمل
بحث أولي ← إعداد مسودة ← تحقق من المصدر ← مراجعة بشرية ← موافقة النشر ← أرشفة.

## ممنوعات
- اختلاق آيات أو أحاديث أو نسبتها بلا مصدر.
- نشر حديث مختلف في صحته دون بيان علمي مناسب.
- إطلاق وعود جازمة بالأجر أو ضمانات لنتائج التبرع.
- إنشاء روابط دفع أو حسابات شخصية أو حملات جمع تبرعات.
- توليد فتاوى تلقائياً أو تقديم الذكاء الاصطناعي كمفتٍ.
